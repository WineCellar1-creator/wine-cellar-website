# Wine Cellar landing page

Static one-page site (HTML + CSS + a small JS file). No build step, no external requests: fonts are bundled.

- `index.html` – page structure, English text
- `app.js` – Polish translations, Play Store link (`PLAY`), screenshot lightbox
- `style.css` – look and layout (colours follow the flyer: oak, crimson, gold)
- `img/screens/` – unaltered app screenshots (resized only)
- `video/` – promo film (premium v3, H.264 1080p, 19 MB; under GitHub's 25 MB web-upload limit), poster and chapters

All files sit in one folder (no subfolders), so you can select everything and upload it in one go.

Check before publishing: the Play link uses package `com.winecellar.app` (taken from the previous site).
